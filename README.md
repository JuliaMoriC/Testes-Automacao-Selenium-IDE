# Testes de Automação com Selenium IDE

## Sobre o Projeto

Este projeto foi desenvolvido utilizando o Selenium IDE para demonstrar a automação de testes em aplicações web.

A automação realiza ações e validações em páginas web, verificando elementos, títulos, textos e navegação entre páginas.

## Ferramenta Utilizada

- Selenium IDE
- Google Chrome
- JavaScript (Execute Script)

## Testes Implementados

- Abertura de páginas web.
- Verificação do título da página.
- Verificação da presença de elementos.
- Clique em links.
- Validação de textos.
- Captura e validação da URL atual.
- Utilização de scripts JavaScript.

## Arquivo do Projeto

O arquivo `projectselenium2.side` contém os comandos de automação desenvolvidos no Selenium IDE.

## Como Executar

1. Instale o Selenium IDE no navegador.
2. Abra o Selenium IDE.
3. Importe o arquivo `projectselenium2.side`.
4. Execute os testes utilizando o botão de reprodução.
